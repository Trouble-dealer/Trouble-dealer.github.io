之前一直是通过 CC-Switch 配置 API 来使用 Codex。今天刚开通了 ChatGPT Plus，想着切换成官方账号登录，没想到过程中遇到了几个小问题。

查询网上方法，折腾了一番后终于解决，记录一下，希望能帮到有同样需求的朋友。

## 1. 从 API 切换到官方账号登录

打开 CC-Switch，切换到第一个 **Official 官方配置**，然后重新打开 Codex，就会进入官方账号登录页面。

直接使用 ChatGPT Plus 账号登录即可。我这次登录没有遇到手机号验证，不过具体是否需要验证，还是以账号实际情况为准。

## 2. 手机远程控制 Codex，连接二维码刷新不出来

想设置手机等移动设备远程控制电脑上的 Codex，结果添加设备时，二维码一直加载不出来。

最后发现是网络代理的问题。开启代理软件的 **TUN 模式**后，二维码就正常刷新出来了，扫描后成功添加设备。

## 3. 旧 API 会话能看到，但继续对话报 401

切换官方账号后，之前使用 API 的会话记录仍然可以看到，但直接继续旧会话时，出现了 `401 Unauthorized` 错误。

我推测，旧会话仍关联之前的 API 认证或服务商配置。

我的解决方法是：**在旧对话中创建新的对话分支**，之后就可以继续交流了，也不用完全重新开始。

## 4. 对话反复重连，最终报 502 错误

登录成功后，正常聊天时又遇到了连续重连 5 次、最终提示 `502` 的问题。

检查网络代理配置后，我将代理软件从**全局代理模式切换为规则代理模式**，问题就解决了，后续对话恢复正常。

## 写在最后

以上就是我这次从 CC-Switch API 接入切换到 Codex 官方 Plus 账号登录的完整踩坑经历。

主要遇到了账号切换、手机远程连接、旧会话 `401` 和网络 `502` 这几个问题，好在最后都顺利解决了。

> 以上解决方法仅基于我个人的设备、网络环境和实际经历，不保证每个人遇到相同问题时都适用。尤其是代理相关问题，可能需要根据自己的网络环境调整。
